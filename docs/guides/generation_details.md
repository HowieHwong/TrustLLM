# Model generation

The current entry points support local Hugging Face causal language models and OpenAI-compatible API endpoints through the same runner.

Start with the [running guide](running.md) for installation, dataset downloads, CLI/Python usage, and resumable outputs.

The [archived generation guide](legacy_generation.md) describes the 0.3 engine and historical provider SDKs. Its model aliases and APIs are not the recommended interface for new experiments.
